# PayLinks
Secure Third-Party Manual Payment Verification Platform
Domain: paylinksv.app

Create Payment Links. Receive Payments Directly.

Money goes directly from Customer GCash to Merchant GCash. PayLinks only records the proof of payment and supports manual verification. PayLinks does not receive or hold customer funds.

## V1 Config
- GCash Only, Manual Verification (4-Point Checklist)
- PHP, Receipts: Yes, Disputes: Yes, Admin: Yes
- Maya / QRPh / Smile WiFi Vouchers: Future Phase
